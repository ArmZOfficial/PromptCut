# แผนปรับปรุง (จากเซสชัน RAW0135, 24 พ.ย. 2569)

เรียงตามผลต่อคุณภาพที่อาร์มเห็น

## 1. เสียงพูดลื่นตั้งแต่รอบแรก

- ทำ voice track จาก source ต่อเนื่อง + room tone เป็นค่าเริ่มต้นของทุก renderer (ตอนนี้มีเฉพาะ `render_v3.py`; `render.py` ของ v1/v2 ยัง fade 12 ms ทุกเซกเมนต์)
- ใช้ word timestamps (Whisper `-ml 1 -sow` หรือ forced alignment) วางจุดตัดและซับ แทนการกระจายเวลาตามจำนวนตัวอักษร
- สร้างสคริปต์ตรวจ "dropout" อัตโนมัติ: นับช่วง < −50 dB ที่ไม่ใช่ช่วงหายใจตามบท

## 2. กระชับโดยไม่เสียเนื้อหา

- ตัดช่วงเงียบภายในประโยคเหลือ 80–120 ms (ไม่ใช่ time-stretch) แล้วเสนออาร์มเป็นทางเลือก A/B
- ถ้าจะตัดประโยค ให้ทำเป็นเวอร์ชันแยกและถามก่อน

## 3. แบรนด์และกราฟิก

- ย้าย component (`card.html`, `pill.html`) เป็นเทมเพลตรับพารามิเตอร์ (ชื่อบริการ, ข้อความปุ่ม) และพิจารณา Remotion เมื่อต้องการแอนิเมชันหลายชั้น
- เพิ่มลูกศร/กรอบแดงชี้จุดใน B-roll แบบคลิปตัวอย่าง (ยังไม่ได้ทำ)

## 4. B-roll

- ถ่าย B-roll ร้านจริงของลูกค้า (ครีมข้างกระทะ, ของสดบนเคาน์เตอร์, ร้านก่อน/หลังจัด) แทน stock — ช็อตลิสต์ใช้ [affiliate-aroll-broll](../affiliate-aroll-broll/SKILL.md)
- ทำ `Insert/assets.csv` ระบุสิทธิ์ (Pexels/Mixkit/ElevenLabs-free) ต่อไฟล์

## 5. Pipeline

- รวม `render.py` + `render_v3.py` เป็น renderer เดียวที่อ่าน plan บน output clock
- cache key ของช็อตต้องรวม path ของ A-roll (เคยใช้ cache ผิดเมื่อเปลี่ยนต้นทาง)
- ใช้ Chrome headless พร้อม `--user-data-dir` ใหม่ทุกครั้ง (Edge คืนภาพเก่า)

## งานค้าง ณ วันที่เขียน
