# ตัดคลิป TikTok ตามรสนิยมของอาร์ม

สกิลนี้สรุปจากเซสชันแก้ `RAW0135` (24 พ.ย. 2569) ที่อาร์มคอมเมนต์ทีละจุดจนได้ `Output/Raw_v3_original-voice_pro.mp4` ใช้คู่กับ [tiktok-pro-showcase](../tiktok-pro-showcase/SKILL.md) (สเปกเลย์เอาต์ ส่งออก safe zone) สกิลนี้คือ **รสนิยม** ที่ทับสเปกนั้นเมื่อขัดกัน

มาตรฐานเดียวที่อาร์มใช้ตัดสิน: **ดูเหมือน editor TikTok มืออาชีพตัด** — เสียงพูดลื่นเป็นธรรมชาติ เนื้อหาครบรู้เรื่อง ภาพไม่กระโดด แบรนด์เด่น SFX/เพลงแค่เสริม

## ขั้นตอน

1. **อ่านต้นทาง** — บท (`Brief/scripts.json`), ฟุตเทจ, คลิปตัวอย่างใน `Example/` ถ้ามี ทำ contact sheet ของตัวอย่าง (`fps=1,tile`) แล้วจดสไตล์: ตำแหน่ง/สีตัวอักษร, การวาง B-roll, จังหวะตัด, เพลง/SFX มีหรือไม่ เสร็จเมื่อเขียนสไตล์ของตัวอย่างได้เป็นข้อ ๆ
2. **ยืนยันคำที่ไม่แน่ใจกับอาร์มก่อนเรนเดอร์จริง** — ชื่อแบรนด์ คำที่ ASR ได้ยินแปลก คำลงท้าย (คะ/ครับ) ถามครั้งเดียวรวมกัน เสร็จเมื่อทุกคำ «ต้องตรวจ» มีคำตอบ หรือแจ้งชัดว่ายังเดาอยู่
3. **วาง edit plan บน output clock** — ช่วงคนพูด, ช่วง B-roll การ์ด, Super Text, SFX ทุกจุดมีเวลา ทุกรอยต่อระหว่างเทค (source กระโดด) ที่เป็นคนพูด→คนพูด ต้องมี B-roll ปิด
4. **เรนเดอร์** ด้วย `.work/tiktok_pro/raw0135/render_v3.py` (แพตเทิร์นอ้างอิง) แล้วทำ QA ครบทุกข้อในหัวข้อ QA เสร็จเมื่อทุกข้อผ่านพร้อมตัวเลข
5. **ส่งงาน** — ส่งไฟล์ (`SendUserFile`) + สรุปสั้นว่าเปลี่ยนอะไร ตัวเลข QA และสิ่งที่ยังค้าง/ตรวจไม่ได้ (เช่น "ยังไม่ได้ฟังด้วยหูจริง")

## รสนิยมด้านภาพ

- **คนพูดอยู่สูง**: หน้าอยู่ราว 1/3 จากบนเฟรม ไม่ปล่อยพื้นที่ว่างเหนือหัว ครอปจาก source 4K ด้วย zoom ≥1.15 แล้วคำนวณ `cy` จากตำแหน่งหน้า (ดู `make_plan_v3a.py`)
- **Punch-in สลับระดับ** (≈1.15 / 1.32 / 1.55) ระหว่างช็อตคนพูด
- **B-roll เป็นการ์ด**: มุมโค้ง ขอบขาว ลอยบนพื้นหลังเบลอของคนพูด (สไตล์คลิปตัวอย่าง) การ์ด 700×1244 บนสุด y≈330 เด้งเข้า 90→100% + slow push ภาพนิ่งใช้ Ken Burns
- **ภาพต้องตรงคำพูด** และวัตถุหลักต้องอยู่ในเฟรมตลอดช็อต (ตรวจเฟรมกลางช็อต เช่น กระทะหลุดเฟรม = เปลี่ยนคลิป)
- **ทุกอย่างอยู่ใน safe zone** x 80–900, y 200–1510 — ด้านบนชน "For You", ด้านล่างชนแคปชัน/ชื่อผู้ใช้

## รสนิยมด้านตัวอักษร

- ฟอนต์ **Kanit ExtraBold** (`assets/fonts/kanit/`, OFL) — แทน Leelawadee ที่อาร์มว่าไม่สวย
- **Hook/CTA box**: ตัวเหลือง `#FFD400` บนกล่องดำ + บรรทัดรองตัวขาวกล่องดำ วางระดับอก ต้องไม่บังปาก/หน้า
- **Keyword บน**: ขาวขอบดำหนา + เงา คำสำคัญสีฟ้า `#00E5FF` เด้ง 0→115→100% คำสร้างทีละคำได้ ("ปัญหา → ปัญหา สินค้า → … ร้านค้า")
- **คำเตือน** เช่น "วางผิดคู่!" สีแดงใต้การ์ด
- ไม่เผาซับเต็มทั้งคลิป (ตามคลิปตัวอย่าง) แต่ส่ง `.srt` คู่ไฟล์ทุกครั้งสำหรับอัปโหลด
- ข้อความบนจอต้องเป็นคำที่พูดจริง ห้ามใส่ claim ที่ไม่มีในบท (เช่น "ฟรี")

## รสนิยมด้านเสียง

- **เสียงพูดเป็นพระเอก ชัด อยู่กลาง ลื่น**
  - ไมค์อัดช่องซ้ายช่องเดียว → ใช้ `pan=stereo|c0=c0|c1=c0` ตรวจ L=R ด้วย `volumedetect`
  - ไม่ใช้ denoise แรง (`afftdn` ทำเสียงบาง) — highpass 75, ลด 250 Hz −2, เพิ่ม 4 kHz +2.5, compressor 2.5:1
  - สร้างเสียงจาก source ต่อเนื่องทั้ง piece (ไม่ fade ตรง punch-in cut กลางประโยค) fade 25 ms เฉพาะรอยต่อเทค + **room tone จริงจากกองถ่าย** รองใต้ทั้งคลิป
  - ไม่เร่งความเร็ว (atempo + loudnorm แบบ dynamic ทำเสียงขาด ๆ) — ทำให้กระชับด้วยการตัดช่วงเงียบ ไม่ใช่ time-stretch
- **เพลง**: เบามาก (Mixkit Pop Track 03 ที่ volume ≈0.07) duck นุ่ม `sidechaincompress ratio=4 release=600` อาร์มชอบ "ดึงขึ้นนิดเดียว" ไม่ใช่ดัง
- **SFX แบบมินิมอล** (อาร์มว่า SFX ถี่ = รก น่ารำคาญ ถูกติมา 3 รอบ): ทั้งคลิปมีแค่ whoosh 1 ครั้งต่อการเข้า B-roll หนึ่งชุด (0.10), pop 1 ครั้งตอน Hook (0.12), ding 1 ครั้งตอนการ์ดแบรนด์ (0.10) — ราว 6 เสียงต่อคลิป 26 วินาที คำ/การ์ดอื่นปล่อยเงียบ ไม่ใช้เสียงบัซเซอร์
- Loudness สุดท้าย −14 LUFS, true peak ≤ −1.5 dB (loudnorm สองรอบแบบ linear)

## จังหวะและเนื้อหา

- **เนื้อหาต้องครบรู้เรื่อง** มากกว่าสั้น — ตัดประโยคทิ้งแล้วอาร์มบอก "ขาดเลยไม่รู้เรื่อง" เสนอการตัดประโยคเป็นตัวเลือกให้อาร์มเลือก ไม่ตัดเอง
- ตัดจบที่จังหวะสวย (ยิ้ม/ค้าง) ก่อนท่าทางนอกบท เช่น เอื้อมถอดไมค์
- **จุดตัดเสียงต้องอยู่ในช่วงเงียบจริง** หาด้วย energy envelope 10 ms (`edges.py`) + ถอดเสียงทดสอบปลายคลิป ไม่ใช้เวลาจากซับที่ประมาณด้วยสัดส่วนตัวอักษร
- คนพูด→คนพูดข้ามเทค = jump cut ต้องปิดด้วย B-roll การ์ด

## QA ก่อนส่ง (ทุกข้อพร้อมตัวเลข)

- `ffprobe`: 1080×1920, CFR 60 fps, H.264 High `yuv420p`, AAC 48 kHz stereo, ขนาด ≤300 MB
- `ebur128`: I ≈ −14 LUFS, peak ≤ −1.5 dB; `volumedetect` L = R
- decode `-xerror` ผ่าน, `freezedetect` d=3 = 0
- Whisper ถอดไฟล์จริงทั้งคลิป: ทุกประโยคในบทครบ ไม่มีคำขาด
- contact sheet ทั้งคลิป + เฟรมรอบทุกรอยต่อ/การ์ด/ข้อความ: ไม่บังหน้า อยู่ใน safe zone วัตถุในการ์ดอยู่ในเฟรม
